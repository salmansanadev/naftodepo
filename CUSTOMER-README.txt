NAFTO DEPO — WINDOWS INSTALLATION

Supported package: Windows 10/11, 64-bit (x64).

1. Double-click Nafto-Depo-Setup-0.1.0-x64.exe.
2. The app installs for your Windows account and opens automatically.
3. Next time, open Nafto Depo from the desktop or Start menu.

No Node.js, npm, PowerShell, VS Code, or internet connection is needed.
All application dependencies are included in the setup file.

The installer is currently unsigned. Windows may display a publisher or
SmartScreen warning. This is separate from the installation workflow;
commercial code signing is not yet configured.

FIRST USE
Add a driver in Driver Khata. Record opening fuel as Stock received.
Record sales as Fuel issued. Choose the driver for credit transactions.
Save a database backup to a USB drive at the end of each working day.

DO NOT distribute the GitHub source ZIP as the customer installation.
Give customers the Setup .exe from a successful Windows installer build.

PILOT SCOPE
Fuel inventory, sales, driver credit/payments, PDF receipts, backups.
Supplier credit, transaction reversals, dip calibration and licensing are
not yet included. Validate operation at a depot before commercial sale.
